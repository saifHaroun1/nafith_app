# Nafith App

Nafith is a mobile application developed to make accessing Ruqyah services easier and more organized for users.

The idea started as a website that provided spiritual healing services based on Islamic Ruqyah, then evolved into a mobile application to improve accessibility and user experience across different devices.

The application provides a simple and clean interface that allows users to browse available services, book appointments, access educational content, and interact with the platform smoothly.

---

# Features

- Responsive and modern UI
- Smooth user experience
- Appointment booking system
- Islamic Ruqyah content
- In-app store section
- Payment section
- Customer reviews section
- Arabic language support

---

# Technologies Used

- Flutter
- Dart
- Responsive Design
